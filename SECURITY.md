# Security policy

Security fixes are made against the latest stable AudioMicPad release. See [GitHub Releases](https://github.com/lilbuda/AudioMicPad/releases/latest) for the current version.

Report suspected vulnerabilities privately using [GitHub's vulnerability reporting form](https://github.com/lilbuda/AudioMicPad/security/advisories/new). Include the affected version, Windows version, the potential impact, and steps to reproduce if known. Remove credentials, recordings, and other personal data from attachments.

Use [GitHub Issues](https://github.com/lilbuda/AudioMicPad/issues) for ordinary bugs. Report vulnerabilities in the separate VB-CABLE driver to its vendor.
